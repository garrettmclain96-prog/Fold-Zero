# FOLD ZERO — Reality Evolution Engine

**Make the non-obvious testable.**

FOLD ZERO is an evolutionary discovery engine. It collides distant signals, attacks the resulting concepts, spawns the cheapest falsifiable experiment, records what reality rejects, and mutates survivors.

## Core loop

**SENSORIUM → COLLIDER → TRIBUNAL → FORGE → GENOME**

- **Reactor** — lock problems, technologies, behaviors, constraints, repos, research and wildcards as atoms.
- **Sensorium** — live/connector-ready intake for GitHub, research, regulation and complaint signals.
- **Black Swan** — inject distant mechanisms deliberately.
- **ZERO ORIGIN** — start with no idea and search for something that should exist.
- **Tribunal** — Skeptic / Engineer / Lawyer / Copycat / Accountant.
- **KILL / MUTATE / SPAWN** — ideas only survive by earning it.
- **Reality Budget** — cap money and time before testing.
- **Forge** — create falsifiable experiments with explicit success/failure thresholds.
- **Genome** — extinction memory, mechanism DNA, experiment history and evolution branches.
- **Prove Me Wrong** — attack a cherished idea before spending real money.

## Truth model

FOLD ZERO visibly separates:
- user observations
- external evidence
- local synthesis
- exploratory Black Swan material

Generated claims are hypotheses, not verified facts. External evidence preserves provenance URLs when available.

## Run

```bash
npm start
```

Open `http://localhost:3000`. Health check: `/health`.

## Data

The full beta is local-first. Atoms, experiments and the genome persist in browser `localStorage` and can be exported/imported as JSON.

## Production evolution

The next cloud layer can move genome state into a dedicated database, proxy external sources server-side for caching/rate limits, and add expedition scheduling + observability without weakening provenance boundaries.
